## 1. บทสรุปผู้บริหาร (Executive Summary)

Vibe Talk เป็น Progressive Web Application (PWA) ที่ช่วยให้ผู้ใช้ชาวไทยฝึกสนทนาภาษาอังกฤษผ่านการโต้ตอบกับ AI Agent ในสถานการณ์จำลองเสมือนจริง ตัว AI จะทำหน้าที่เป็นคู่สนทนา พร้อมตรวจสอบและแก้ไขแกรมม่าให้แบบเรียลไทม์ นอกจากนี้ยังมีระบบจัดการคลังคำศัพท์ส่วนตัวและ Dashboard แสดงสถิติข้อผิดพลาด เพื่อให้ผู้ใช้เห็นพัฒนาการของตนเอง

**จุดเด่น**: ใช้งานได้ทุกที่ทุกเวลา ไม่ต้องติดตั้งแอปผ่าน Store, ข้อมูลทั้งหมดเก็บในเครื่องผู้ใช้ (Privacy-First), ใช้ AI ตรวจแกรมม่าพร้อมคำอธิบายภาษาไทย

---

## 2. ปัญหาทางธุรกิจ (Business Problem)

### 2.1 สถานการณ์ปัจจุบัน

- คนไทยจำนวนมากมีทักษะการสนทนาภาษาอังกฤษจำกัด แม้จะมีความรู้ด้านไวยากรณ์
- การฝึกสนทนากับเจ้าของภาษาจริงมีค่าใช้จ่ายสูงและไม่สะดวก
- แอปฝึกภาษาในตลาดส่วนใหญ่เน้นคำศัพท์หรือแบบฝึกหัด ไม่เน้นการสนทนาแบบ real-time
- แอปที่มีฟีเจอร์สนทนาด้วย AI มักมีค่าใช้จ่ายรายเดือนสูง
- ผู้ใช้หลายคนกังวลเรื่องความเป็นส่วนตัวของข้อมูล

### 2.2 โอกาสทางธุรกิจ

- ตลาด EdTech ในไทยกำลังเติบโต โดยเฉพาะด้านการเรียนภาษา
- เทคโนโลยี Generative AI (LLM) มีความสามารถด้านภาษาและความเข้าใจบริบทที่ดีขึ้นอย่างมาก
- PWA ช่วยลดต้นทุนการพัฒนา (Single Codebase รองรับทุกแพลตฟอร์ม) และลดแรงเสียดทานในการติดตั้ง
- การใช้ AI API แบบ Pay-per-use ทำให้ผู้ใช้จ่ายตามการใช้งานจริง ถูกกว่าค่าสมาชิกรายเดือน

## 3. เป้าหมายทางธุรกิจ (Business Objectives)

| ลำดับ | เป้าหมาย | ตัวชี้วัด (KPI) |
|---|---|---|
| BO-01 | เป็นเครื่องมือฝึกภาษาอังกฤษที่เข้าถึงง่ายสำหรับคนไทย | จำนวนผู้ใช้งาน Active รายเดือน (MAU) |
| BO-02 | ลดค่าใช้จ่ายในการฝึกภาษาอังกฤษของผู้ใช้ | ต้นทุนต่อเซสชัน ≤ 5 บาท (ค่า API) |
| BO-03 | สร้างประสบการณ์การเรียนรู้แบบ Personalized | อัตราการกลับมาใช้งาน (Retention Rate) |
| BO-04 | สร้างความไว้วางใจด้านข้อมูลส่วนบุคคล | ข้อมูลทั้งหมดเก็บบนเครื่องผู้ใช้เท่านั้น |

## 4. ขอบเขตของโปรเจกต์ (Project Scope)

### 4.1 In Scope ✅

| Module | รายละเอียด |
|---|---|
| **Chat** | ฝึกสนทนาภาษาอังกฤษกับ AI ผ่าน 8 สถานการณ์ |
| **Grammar Correction** | ตรวจจับและแก้ไขข้อผิดพลาดด้านแกรมม่า (9 ประเภท) พร้อมคำอธิบายภาษาไทย |
| **Conversation History** | บันทึกประวัติบทสนทนา เรียกดูและสนทนาต่อจากเดิมได้ |
| **Dashboard** | แสดงสถิติข้อผิดพลาดแยกตามประเภท, จำนวนครั้งที่ฝึก |
| **Vocabulary** | จัดการคลังคำศัพท์ส่วนตัว (เพิ่ม/ลบ/แก้ไข), AI Auto-fill, ตรวจสอบคำซ้ำ, Spell Check, Text-to-Speech, ติดตามสถานะรู้แล้ว/ยังไม่รู้ |
| **Settings** | ตั้งค่า DeepSeek API Key |
| **PWA** | ติดตั้งลงหน้าจอมือถือได้, ใช้งานแบบ Full Screen, รองรับ Safe Area |

### 4.2 Out of Scope ❌

- ระบบสมัครสมาชิก/Login (ใช้ Local Storage แทน)
- ระบบชำระเงิน
- ระบบ Backend/Cloud Storage
- ระบบแชร์คะแนน/Social Features
- แอป Native iOS/Android (ใช้ PWA แทน)
- การฝึกทักษะ Writing/Reading (เน้น Speaking ผ่านการพิมพ์)
- รองรับหลายภาษา (UI เป็นภาษาไทยเท่านั้น)

## 6. ข้อจำกัดและสมมติฐาน (Constraints & Assumptions)

### 6.1 ข้อจำกัด

| ข้อจำกัด | รายละเอียด |
|---|---|
| **Budget** | พัฒนาโดยทีมขนาดเล็ก (1-2 คน) ภายใน 3 เดือน |
| **Platform** | PWA เท่านั้น ไม่มี Native App |
| **AI Provider** | DeepSeek API เท่านั้น (ต้นทุนต่ำกว่า GPT-4 ประมาณ 10 เท่า) |
| **Storage** | IndexedDB บน Browser เท่านั้น (จำกัดประมาณ 50-100 MB ขึ้นอยู่กับ Browser) |
| **Network** | ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อใช้งาน AI Chat |

### 6.2 สมมติฐาน

- ผู้ใช้สามารถสมัครและจัดการ API Key ของ DeepSeek ได้ด้วยตนเอง
- ผู้ใช้มีอุปกรณ์ที่รองรับ PWA (iOS 11.3+ หรือ Android 5.0+)
- ผู้ใช้มีความรู้ภาษาอังกฤษระดับ Beginner ถึง Intermediate
- AI Model (DeepSeek Chat) มีความสามารถด้านภาษาเพียงพอสำหรับการตรวจแกรมม่า

## 7. ความเสี่ยง (Risks)

| Risk ID | ความเสี่ยง | ความรุนแรง | โอกาสเกิด | แนวทางจัดการ |
|---|---|---|---|---|
| R-01 | DeepSeek API เปลี่ยนแปลงราคาหรือปิดบริการ | สูง | ต่ำ | ออกแบบให้เปลี่ยน AI Provider ได้ง่าย (ใช้ OpenAI SDK) |
| R-02 | AI ให้คำตอบที่ไม่ถูกต้องหรือไม่เหมาะสม | ปานกลาง | ปานกลาง | มี System Prompt ควบคุม + ผู้ใช้รับทราบว่า AI อาจผิดพลาด |
| R-03 | IndexedDB ข้อมูลสูญหาย (ผู้ใช้ลบ Cache) | ปานกลาง | ปานกลาง | แสดงคำเตือนก่อนลบข้อมูล + อาจเพิ่ม Export/Import ในอนาคต |
| R-04 | ประสิทธิภาพบนมือถือรุ่นเก่า | ต่ำ | ปานกลาง | ใช้ Next.js + Code Splitting, ทดสอบบนอุปกรณ์หลากหลาย |

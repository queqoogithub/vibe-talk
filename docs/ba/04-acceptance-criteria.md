## Epic 1: AI Chat

### US-01: เลือกสถานการณ์สนทนา

| AC ID | Criteria | Given | When | Then |
|---|---|---|---|---|
| AC-01-01 | แสดงรายการสถานการณ์ทั้งหมด | ผู้ใช้เปิดแอปครั้งแรก | หน้า Chat โหลดเสร็จ | เห็นปุ่มเลือกสถานการณ์ทั้ง 8 แบบ พร้อม Emoji และชื่อภาษาไทย |
| AC-01-02 | เลือกสถานการณ์ได้ | ผู้ใช้อยู่หน้า Chat | กดปุ่มสถานการณ์ "สั่งอาหาร" | AI เริ่มบทสนทนาด้วยข้อความทักทายในบทบาทพนักงานเสิร์ฟ |
| AC-01-03 | สถานการณ์ที่เลือกถูกไฮไลต์ | ผู้ใช้เลือกสถานการณ์ "สั่งอาหาร" แล้ว | เข้าหน้า Chat | ปุ่ม "สั่งอาหาร" แสดงสถานะ Active แตกต่างจากปุ่มอื่น |

### US-02: ส่งข้อความและรับการตอบกลับ

| AC ID | Criteria | Given | When | Then |
|---|---|---|---|---|
| AC-02-01 | ส่งข้อความได้ | ผู้ใช้พิมพ์ "Hello" ในช่องข้อความ | กดปุ่ม Send | ข้อความ "Hello" แสดงในฟองแชทฝั่ง User |
| AC-02-02 | AI ตอบกลับ | ผู้ใช้ส่งข้อความแล้ว | รอ AI ประมวลผล | แสดงข้อความตอบกลับภาษาอังกฤษในฟองแชทฝั่ง AI |
| AC-02-03 | แสดง Loading Indicator | ผู้ใช้ส่งข้อความแล้ว | กำลังรอ AI ตอบ | แสดง Animation พิมพ์ 3 จุด (... Typing) |
| AC-02-04 | แจ้ง Error เมื่อไม่มี API Key | ผู้ใช้ยังไม่ได้ตั้งค่า API Key | พยายามส่งข้อความ | แสดงข้อความแจ้งให้ไปตั้งค่า API Key |
| AC-02-05 | แจ้ง Error เมื่อ Network ล้มเหลว | ไม่มีการเชื่อมต่ออินเทอร์เน็ต | พยายามส่งข้อความ | แสดงข้อความแจ้ง Network Error |
| AC-02-06 | ป้องกันการส่งข้อความเปล่า | ช่องข้อความว่าง | กดปุ่ม Send | ไม่เกิดการส่งข้อความ (ปุ่ม Send อาจถูก Disable) |

### US-04: เริ่มบทสนทนาใหม่

| AC ID | Criteria | Given | When | Then |
|---|---|---|---|---|
| AC-04-01 | กลับไปเลือกสถานการณ์ | กำลังสนทนาอยู่ | กดปุ่ม New Chat / กลับ | กลับสู่หน้าจอเลือกสถานการณ์ |
| AC-04-02 | บทสนทนาเดิมถูกบันทึก | กำลังสนทนาแล้วกดเริ่มใหม่ | กลับไปดูประวัติ | พบบทสนทนาเดิมในรายการประวัติ |

### US-05: ประวัติบทสนทนา

| AC ID | Criteria | Given | When | Then |
|---|---|---|---|---|
| AC-05-01 | แสดงรายการประวัติ | มีบทสนทนาเก่าอยู่ | เปิดรายการประวัติ | เห็นรายการเรียงตามเวลาใช้งานล่าสุด (ใหม่สุดขึ้นก่อน) |
| AC-05-02 | แสดงชื่อสถานการณ์ | มีบทสนทนา "สั่งอาหาร" | ดูรายการประวัติ | แสดงชื่อสถานการณ์ "สั่งอาหาร" ในรายการ |
| AC-05-03 | สนทนาต่อจากประวัติ | มีบทสนทนาเก่า | แตะที่รายการ | เปิดบทสนทนานั้นและพิมพ์ต่อได้, AI มีบริบทเดิม |
| AC-05-04 | แสดงวันที่ | มีบทสนทนาจากเมื่อวาน | ดูรายการประวัติ | แสดงวันที่ของบทสนทนา |

### US-06: ลบบทสนทนา

| AC ID | Criteria | Given | When | Then |
|---|---|---|---|---|
| AC-06-01 | ลบบทสนทนาได้ | มีบทสนทนาอยู่ในประวัติ | กด Delete | บทสนทนาถูกลบออกจาก IndexedDB และหายจากรายการ |

## Epic 2: Grammar Correction

### US-07: AI ตรวจแกรมม่า

| AC ID | Criteria | Given | When | Then |
|---|---|---|---|---|
| AC-07-01 | ตรวจจับข้อผิดพลาด | ผู้ใช้พิมพ์ "I go to school yesterday" | AI ได้รับข้อความ | AI แสดงการ์ดแก้ไข: "go" → "went" + คำอธิบาย |
| AC-07-02 | ไม่แสดงเมื่อไม่มีข้อผิดพลาด | ผู้ใช้พิมพ์ "I went to school yesterday" | AI ได้รับข้อความ | ไม่มีการ์ดแก้ไขปรากฏ |
| AC-07-03 | แสดงหลายข้อผิดพลาด | ผู้ใช้พิมพ์ข้อความที่มีหลายจุดผิด | AI ได้รับข้อความ | แสดงการ์ดแก้ไขทุกจุดที่พบ |

### US-08: คำอธิบายภาษาไทย

| AC ID | Criteria | Given | When | Then |
|---|---|---|---|---|
| AC-08-01 | คำอธิบายเป็นไทย | AI ตรวจพบข้อผิดพลาด | แสดงการ์ดแก้ไข | คำอธิบายเป็นภาษาไทย (เช่น "ควรใช้ Past Tense เพราะเป็นเหตุการณ์ในอดีต") |

### US-09: เปรียบเทียบข้อความเดิมกับที่แก้ไข

| AC ID | Criteria | Given | When | Then |
|---|---|---|---|---|
| AC-09-01 | แสดง Original และ Corrected | AI ตรวจพบข้อผิดพลาด | แสดงการ์ดแก้ไข | เห็นข้อความเดิมที่ผิด และข้อความที่แก้แล้วในบรรทัดแยก |

### US-10: แสดงประเภทข้อผิดพลาด

| AC ID | Criteria | Given | When | Then |
|---|---|---|---|---|
| AC-10-01 | แสดง Label ประเภท | AI พบข้อผิดพลาด Tense | แสดงการ์ดแก้ไข | แสดงป้าย "Tense (กาล)" |

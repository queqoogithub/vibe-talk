## 1. Design Principles

- **Mobile-first**: ออกแบบสำหรับมือถือก่อน (375px width base), Responsive สำหรับ Tablet และ Desktop
- **Color Palette**: โทนกาแฟพาสเทล (Pastel Coffee) — สบายตา อ่านง่าย
- **Thai Language UI**: ใช้ภาษาไทยทั้งหมดใน UI (ยกเว้นข้อความภาษาอังกฤษที่ผู้ใช้พิมพ์)
- **Touch-friendly**: ปุ่มและพื้นที่กดมีขนาด ≥ 44px
- **Safe Area**: รองรับ iPhone Notch / Dynamic Island
